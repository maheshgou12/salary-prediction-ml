# 💼 Salary Prediction System (Machine Learning + Streamlit)

## 📌 Project Overview
This project is an end-to-end Machine Learning web application that predicts the expected salary (CTC) of a candidate based on:

- Years of Experience
- Test Score
- Interview Score

The system uses multiple regression algorithms and selects the best performing model based on evaluation metrics.

---

## 🚀 Features
✅ Data Cleaning & Preprocessing  
✅ Exploratory Data Analysis (EDA)  
✅ Correlation Heatmap Visualization  
✅ Model Training & Comparison  
✅ Cross Validation  
✅ Feature Importance Analysis  
✅ Model Serialization using Pickle  
✅ Real-Time Salary Prediction  
✅ Interactive Web Application using Streamlit  

---

## 🤖 Machine Learning Models Used
- Linear Regression  
- Decision Tree Regressor  
- Random Forest Regressor (Best Model)

---

## 📊 Model Evaluation
Evaluation Metric: **R2 Score**

Random Forest achieved the highest prediction accuracy.

---

## 🖥️ Web Application
The trained model is deployed using **Streamlit**, allowing users to input candidate details and get real-time salary prediction.
